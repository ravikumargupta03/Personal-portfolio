## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/ravikumargupta03/Personal-portfolio.git
```

### Navigate to the project

```bash
cd Personal-portfolio
```

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```
